# Bilder / Images

Die Website verwendet aktuell gestaltete Platzhalter-Blöcke (`PlaceholderImage`-Komponente)
sowie eine stilisierte SVG-Karte. Sobald professionelle Fotos vorliegen, hier ablegen und die
jeweilige `PlaceholderImage` in der Seiten-Komponente durch `next/image` ersetzen.

**Bildsprache** (siehe Design): echte, professionelle Fotografie — aufgeräumte Innenräume,
ordentlich gestapelte Kartons, leere besenreine Räume, renovierte Zimmer. Keine Cartoon-
Illustrationen, kein Umzugswagen-Clipart. Empfohlen: dezentes Navy-Duotone/Overlay (10–20 %)
auf Hero-Bildern.

## Alt-Text-Muster

`[Marke] [Leistung] München — [kurze Beschreibung der Szene]`
z. B. „Super Umzug Möbeltransport München — Umzugsteam trägt Umzugskartons in Lieferwagen".
EN: "Super Umzug furniture transport Munich — moving team carrying boxes into van".
